⚙️ Configure la conexión a Google Sheets para comenzar.
Paso inicial
Configuración Google Sheets
Conecte el formulario a su Google Sheet para tener INSERT y UPDATE reales sin riesgo de duplicados. Solo se configura una vez.
🔗 Esta opción usa la Google Sheets API v4 con una clave de API pública (lectura) y OAuth2 para escritura. El formulario se comunica directamente con Google — no hay servidor intermediario.
1 Crear la Google Sheet de datos

Abra Google Sheets, cree una hoja nueva y renombre la primera pestaña como "Detalle". Agregue una segunda pestaña llamada "Solicitudes". Luego pegue los encabezados:

# Solicitud Fecha Solicitud Res. Fecha Res. Importador Rut Origen Especie Variedades Cubículo Fecha de Ingreso Año de Ingreso Fecha Injertación N° Plantas Fecha aprox. Levant. Estado Análisis Fecha Estimada Muestreo Muestreada? Fecha muestreo/Indexaje Fecha de envío Folio Corr. Desde Corr. Hasta N° Muestras SPS análisis CORE/Factura SPS estadía CORE/Factura3 Patógenos Estado Análisis Resultado Técnica Fecha Informe Fitosanitario Terminada Res. Término Fecha Res.4 Liberada Entregada Obs. Status
2 Obtener las credenciales de Google
a) Vaya a console.cloud.google.com → Crear proyecto → Habilitar Google Sheets API
b) En Credenciales → Crear Clave de API → Restringirla a Sheets API y a su dominio
c) También en Credenciales → Crear ID de cliente OAuth 2.0 (tipo: Aplicación web) → Agregar http://localhost y la URL donde alojará el formulario como origen autorizado
d) Copie el Sheet ID desde la URL de su Google Sheet:
https://docs.google.com/spreadsheets/d/ESTE_ES_EL_SHEET_ID/edit
3 Ingresar credenciales aquí
4 (Opcional) Importar histórico desde Excel

Si tiene datos históricos en su planilla Excel, puede importarlos directamente a Google Sheets con un clic.
